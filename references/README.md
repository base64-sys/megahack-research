# references

Reserved home for external material — Geode and Geometry Dash documentation, format
specifications, third-party research — as named in [AGENTS.md](../AGENTS.md) ("Writing
notes") and the repository layout in [README.md](../README.md).

**Status: nothing has been collected yet.** The directory exists so the links and the
layout it describes resolve; it is not evidence for any claim in `notes/`.

Rules for anything added here:

- Cite the source and the date it was consulted.
- Keep it external material only: no Absolllute assets, no binaries, no user data.
- A note that depends on something collected here must link to it with a path relative to
  the note (from `notes/`, that is `../references/...`).
